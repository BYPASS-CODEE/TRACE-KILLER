### ⟨ ./deploy --recon ⟩

</div>

```bash
# ── Windows / Linux ───────────────────────────────────────────
git clone https://github.com/BYPASS-CODEE/TRACE-KILLER
cd TRACE-KILLER && pip install colorama requests
python trace_killer.py                      # interactive menu

# ── Optional (better radar stats) ─────────────────────────────
pip install psutil                          # cpu/ram live meters

# ── No root required ──────────────────────────────────────────
# works directly on your own Windows/Linux — no kali, no vpn
```

```bash
# ── Arsenal in one terminal ──────────────────────────────────
trace-killer track example.com   # resolve · ping · trace · geoip
trace-killer netscan             # devices + vendor lookup
trace-killer portscan 192.168.1.1  # concurrent port sweep
trace-killer watch               # live intrusion monitor
trace-killer radar               # animated radar dashboard
trace-killer report              # saved scan reports
```

> 🇮🇷 ابزار ترمینالی جمع‌آوری اطلاعات و شناسایی شبکه — ردیابی IP/دامنه، اسکن دستگاه‌ها، اسکن پورت، هشدار نفوذ و داشبورد رادار.
> ⚠️ **این ابزار هنوز کامل تست نشده** — روی سیستم‌های مختلف ممکنه تفاوت‌هایی داشته باشه؛ اول روی شبکه خودت امتحانش کن.
> فقط برای **شبکه‌ها و اطلاعات خودت** استفاده کن؛ اسکن دیگران بدون اجازه جرم است و مسئولیتش با خودته.

### ⟨ ./modules --list ⟩

</div>

| ⟦ module ⟧ | ⟦ delivers ⟧ |
|:--|:--|
| `tracker`    | resolve → ping → traceroute → full GeoIP (country · city · ISP · ASN · coords · proxy check) |
| `netscan`    | device discovery — ping sweep + ARP map · vendor lookup via OUI database · saved report |
| `portscan`   | concurrent scan of 56 common ports or custom range · service name for every open port |
| `watch`      | live ARP monitoring — instant alert on new device join/leave · vendor identified |
| `radar`      | animated radar sweep · CPU/RAM/OS meters · local & public IP panel |
| `smartiface` | auto-detects real Wi-Fi/Ethernet — skips VPN/TUN/virtual adapters |
| `report`     | timestamped logs + network scan reports saved to disk |
